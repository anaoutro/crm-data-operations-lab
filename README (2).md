# CRM automation portfolio demos

Independent demonstrations using synthetic `.test` contacts. No CRM account or paid software is needed. No external messages are sent.

Run with Python 3.10+:

```bash
python hubspot_demo.py
python ghl_demo.py
python zoho_demo.py
python salesforce_demo.py
```

Each script reads a nearby input file and writes a result file. These are offline prototypes of business logic, not live HubSpot, GoHighLevel, Zoho or Salesforce integrations. For production, validate platform API, access scopes, CRM plan, consent, retention, rate limits and data mapping with the client.
