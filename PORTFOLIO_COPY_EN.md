# Upwork portfolio item

**Title:** B2B Lead Research, CRM Data QA & Automated Excel Dashboard

**Description:** I built a working account research and qualification system for an appointment software use case. The project uses 10 real South African businesses identified from their public official websites. Each account has a source URL and an observed booking or location signal. A Python pipeline preserves the 12-row intake, identifies two deliberately duplicated rows, and generates a clean 10-account CRM import draft, exception queue, campaign hypotheses and a run manifest. The Excel workbook adds an interactive research queue, a formula-driven dashboard, and an editable marketing capacity plan.

This is an independently built portfolio project, not a client engagement. These are researched **company accounts**, not verified decision makers or sales-ready leads. No outreach or conversion is claimed.

**My contribution:** ICP definition, public-source research, scoring model, duplicate and source checks, CSV automation, Excel dashboard, CRM field mapping, campaign hypotheses and documentation.

**Skills:** Lead Generation; B2B Marketing; Data Entry; Data Cleaning; Microsoft Excel; Python Automation; CRM Data Management.
